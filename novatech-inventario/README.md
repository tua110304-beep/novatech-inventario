# NovaTech Inventario

Sistema de inventario de productos para **NovaTech Solutions**, desarrollado como
Actividad Integradora de Git Flow.

## Descripción

Este proyecto permite administrar productos con los siguientes campos:

- ID
- Nombre
- Precio
- Categoría
- Stock

## Tecnologías

- Node.js
- Express
- HTML / CSS / JavaScript (vanilla)

## Instalación

```bash
npm install
npm start
```

La aplicación quedará disponible en `http://localhost:3000`.
